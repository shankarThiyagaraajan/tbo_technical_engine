## What changed
Kit 2.5 on today's code, no mode change (remove-lab-mode row D2-5k2): `tbo-platform-kit` moves from `~=1.0` (tbo_platform `4e92fc0`, kit 1.0.0) to `~=2.5` at `8df4ffc` (kit 2.5.0, tbo_platform `8df4ffceb25716f264d74b9a2bf6a06d965afea2`); `uv.lock` changes only the kit. Unset `TBO_MODE` behaves as before; no lab guard was touched.
1. Start check: `create_app` refuses a route without `requires()`. All routes of this app are guarded; `unguarded_routes(app) == []` (pinned in `tests/test_route_guard.py`, with a test that the app starts and one that an unguarded route is refused). The app builds one way only (service tokens), so there is no realm variant. `owner=` and `step_up=` are not used; who may read and write is unchanged.
2. Consumers (candles, feed status, universe, calendar, indices): built only by `RecreatingConsumer`, which now passes kit 2.5's `transient_max_age=None` and `transient=is_outage` (`consumers/retry.py`), so kit 1.0's rule stays: any `OSError`, `UpstreamUnavailable` and `UpstreamRefused` keep an entry pending, retried every minute for as long as the outage lasts, never dead-lettered by age; a bug or bad event dead-letters after 5 tries. Kit 2.5 recreates a lost group itself but no longer lets the subclass see the NOGROUP error, so `on_group_lost` (warm-up, index history) is now called from `run_once` when the kit cleared its group flag; two existing tests (`test_a_lost_index_group_asks_for_the_history_again`, the Redis-comes-back-empty drill) failed on kit 2.5 until that was done.
3. Order (kit 2.5 keeps none): `Readiness.on_feed_status` ignores a `feed.status` whose `changed_at` is older than the one held (an older unhealthy one still asks for a warm-up, as in order). Universe (`(trade_date, universe_version)`), index candles and candles (`revision`) were already guarded; the calendar handler is a refresh and holds no state. Each has a test in `tests/consumers/test_retry_and_order.py`.
4. Token issuer 401 or 403 is `UpstreamRefused`; no handler here calls a peer. Verifier texts changed ("A token is required."); nothing here depends on them. Celery: the kit's start guard refuses only live without the go-live sign-off.
